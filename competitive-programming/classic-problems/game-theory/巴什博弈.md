# 1 巴什博弈

巴什博弈(bash game)是一个涉及 $2$ 名玩家的双人博弈，属于公平组合游戏的典型例子。

博弈中有一堆总数为 $n$ 的物品，$2$ 名玩家轮流从中拿取物品。
每次至少拿 $1$ 件，至多拿 $m$ 件，不能不拿，最终将物品拿完者获胜。

若 $n \% (m+1) \neq 0$：先手必胜
若 $n \% (m+1) = 0$：后手必胜

根据组合游戏的性质即可推断出结论。

对于 $1 \le i \le m$，处于 $i$ 位置的玩家都可以拿完所有物品，该点必胜点 N。
对于 $i = m + 1$，处于该位置的玩家都只能进入必胜点，因此该点为必败点 P。
依次类推即可得出结论。
