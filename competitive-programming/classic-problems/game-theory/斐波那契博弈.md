# 1 斐波那契博弈

博弈中有一堆总数为 `n` 的物品， `2` 名玩家轮流从中拿取物品。
先取者第 `1` 次可以取任意多个，但不能全部取完，以后每次取的物品数不能超过上次取子数的 `2` 倍。最终将物品拿完者获胜。

当且仅当初始物品数 $n$ 为斐波那契数时，先手必败。

这里要使用**齐肯多夫定理**，即

>[!theorem]
>任何一个正整数都可以唯一表示为若干个不连续的斐波那契数之和。

设 $F_i$ 为斐波那契数。
当 $n$ 不是斐波那契数，先手可以对 $n$ 进行齐肯多夫分解：$$n = F_{i_1} + F_{i_2} + \dots + F_{i_k}$$ 取走最小项 $F_{i_1}$ ，一定满足 $2F_{i_1}<F_{i_2}$ ，因此后手无法取走整个 $F_{i_2}$ 。
先手通过这种方式每次都可以取走每个分解的最小项。

当 $n$ 为斐波那契数，先手第一次取走 $x$ 个物品 $(1\le x < F_m)$
1. 如果 $x \ge \frac{1}{3}F_m$ ：剩下 $F_m - x$ 个物品，后手能取的上限为 $2x\ge \frac{2}{3}F_m$，能全拿走。
2. 如果 $x<\frac{1}{3}F_m$ ：由于 $F_{m-1}<F_m-x<F_m$ 剩下的 $n'=F_m-x$ 肯定不是斐波那契数。

证明： $F_{m-1}<\frac{2}{3}F_m$ 
将 $F_m=F_{m-1} + F_{m-2}$ 代入得 $$F_{m-1}<2F_{m-2}$$ 将 $F_{m-1}=F_{m-2}+F_{m-3}$ 代入得 $$F_{m-3}<F_{m-2}$$ 得证。
