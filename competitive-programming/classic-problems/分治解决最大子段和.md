# 1 分治

设当前区间是 $a[l\dots r]$，中点是 $\mathrm{mid}$。
任取一个连续子数组 $a[i\dots j]$，其中 $l\leq i < j \leq r$。它相对于中点只有三种可能：
1. 完全在左半：$j\leq \mathrm{mid}$
2. 完全在右半：$\mathrm{mid}\leq i$
3. 跨越中点：$i\leq \mathrm{mid}, \mathrm{mid} + 1\leq j$

因此全局最大子数组一定属于这三者之一。
而我们对三者分别求了最大值再取他们之中的最大值，所以不会漏掉最优解。

每一层把所有子问题的工作量加起来是 $O(n)$，而递归深度是 $O(\log n)$，所以总复杂度是：$O(n\log n)$。

```cpp
int work(const vector<int>& a, int l, int r) {
    if (l == r) return a[l];
    int mid = l + (r - l) / 2;
    int left_max = work(a, l, mid);
    int right_max = work(a, mid + 1, r);
    int left_suf = INT_MIN;
    int cur = 0;
    for (int i = mid; i >= l; i--) {
        cur += a[i];
        chmax(left_suf, cur);
    }
    int right_pre = INT_MIN;
    cur = 0;
    for (int i = mid + 1; i <= r; i++) {
        cur += a[i];
        chmax(right_pre, cur);
    }
    return max({left_max, right_max, left_suf + right_pre});
}
```
