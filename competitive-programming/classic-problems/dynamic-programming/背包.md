# 1 01 背包

假设你有一个背包，容量为 $V$。
现在有 $n$ 个物品，第 $i$ 个物品的重量是 $\mathrm{w}[i]$，价值是 $\mathrm{v}[i]$。
在不超过背包容量的前提下，求背包内物品的最大总价值。
## 1.1 算法

我们定义 $\mathrm{dp}[i][j]$ 为：在前 i 个物品中进行选择，当背包容量限制为 j 时，能获得的最大价值。
有状态转移方程
$$\mathrm{dp}[i][j] = \max(\mathrm{dp}[i-1][j], \mathrm{dp}[i-1][j - \mathrm{w}[i]] + \mathrm{v}[i])$$
观察方程发现，$\mathrm{dp}[i][j]$ 只取决于上一行 $\mathrm{dp}[i-1]$ 的数据。因此，我们只需要一个一维数组 $\mathrm{dp}[j]$。
有状态转移方程
$$\mathrm{dp}[j]=\max(\mathrm{dp}[j],\mathrm{dp}[j-\mathrm{w}[i]]+\mathrm{v}[i])$$
注意：这里的状态 $\mathrm{dp}[j]$ 依赖于下标小于 j 的状态，因此下标 j 要从大到小进行更新才能保证每个物品只选择了一次，避免重复选择物品。

```cpp
void solve() {
    int n, V;
    cin >> n >> V;
    vector<int> v(n), w(n);
    for (int i = 0; i < n; i++) cin >> v[i] >> w[i];
    vector<int> dp(V + 1);
    for (int i = 0; i < n; i++) {
        for (int j = V; j >= w[i]; j--) {
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
    cout << dp[V];
}
```

# 2 可达性背包

假设你有一个背包，容量为 `V`。
现在有 `n` 个物品，第 `i` 个物品的重量是 `w[i]` ，价值是 `v[i]` 。
求背包能否恰好被完全填满，并求被完全填满时的最大总价值。
## 2.1 算法

定义 `dp[i][j]` 为加入第 `i` 个物品，是否能装满容量为 `j` 的背包。
有状态转移方程 $$dp[i][j]=dp[i-1][j]\vee  dp[i-1][j-w[i]]$$
同样的可以进行状态压缩，压缩为一维。

```cpp
void solve() {
    int n, V;
    cin >> n >> V;
    vector<int> v(n), w(n);
    for (int i = 0; i < n; i++) cin >> v[i] >> w[i];
    vector<int> dp(V + 1);
    for (int i = 0; i < n; i++) {
        for (int j = V; j >= w[i]; j--) {
            if (dp[j - w[i]] || j == w[i]) dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
    cout << dp[V];
}
```

同时发现，状态的转移其实可以表示为位运算左移 `w[j]` 位，可以用 `bitset` 进一步压缩空间。

```cpp
void solve() {
    int n, V;
    cin >> n >> V;
    vector<int> w(n);
    for (int i = 0; i < n; i++) cin >> w[i];
    bitset<MAXN> dp;
    dp[0] = 1;
    for (int i = 0; i < n; i++) {
        dp |= dp << w[i];
    }
    cout << dp[V];
}
```

# 3 完全背包

假设你有一个背包，容量为 `V`。
现在有 `n` 种物品，第 `i` 种物品的重量是 `w[i]` ，价值是 `v[i]` 。
每种物品的数量无限。在不超过背包容量的前提下，求背包内物品的最大总价值。
## 3.1 算法

我们定义 `dp[i][j]` 表示：在前 `i` 个物品中进行选择，当背包容量限制为 `j` 时，能获得的最大价值。
有状态转移方程 $$dp[i][j] = \max(dp[i-1][j], dp[i][j - w[i]] + v[i])$$ 注意， $\max$ 项中的第二项的下标为 `i` ，表示的是第 `i` 件物品可以选择多次，这是选择第 `i` 件物品的状态的叠加。

同样的，我们可以对状态进行压缩。

```cpp
void solve() {
    int n, V;
    cin >> n >> V;
    vector<int> v(n), w(n);
    for (int i = 0; i < n; i++) cin >> v[i] >> w[i];
    vector<int> dp(V + 1);
    for (int i = 0; i < n; i++) {
        for (int j = w[i]; j <= V; j++) {
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
    cout << dp[V];
}
```

# 4 多重背包

假设你有一个背包，容量为 `V`。
现在有 `n` 种物品，第 `i` 种物品的重量是 `w[i]` ，价值是 `v[i]` ，数量是 `c[i]` 。
在不超过背包容量的前提下，求背包内物品的最大总价值。
## 4.1 算法

实际上我们可以把同种物品拆分成多个物品组合，然后用 01 背包解决这类问题。

在此基础上，我们可以使用二进制优化来简化这个拆分的过程。
也就是说，将数量拆分成 `1, 2, 4...` 的形式，保证每种数量都可以通过选择出现。

```cpp
void solve() {
    int n, V;
    cin >> n >> V;
    vector<int> v, w;
    for (int i = 0; i < n; i++) {
        int val, wei, cnt;
        cin >> val >> wei >> cnt;
        for (int k = 1; k <= cnt; k <<= 1) {
            v.emplace_back(val * k);
            w.emplace_back(wei * k);
            cnt -= k;
        }
        if (cnt) {
            v.emplace_back(val * cnt);
            w.emplace_back(wei * cnt);
        }
    }
    vector<int> dp(V + 1);
    for (int i = 0; i < w.size(); i++) {
        for (int j = V; j >= w[i]; j--) {
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
    cout << dp[V];
}
```
