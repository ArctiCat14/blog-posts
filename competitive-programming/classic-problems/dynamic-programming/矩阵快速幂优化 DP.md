# 1 矩阵快速幂优化 DP

矩阵快速幂优化 DP 是处理长步数、小状态递推问题的核心优化工具。
它的本质就是把 DP 递推式写成矩阵乘法的形式，再利用快速幂把 $O(m)$ 降到 $O(S^3 \log m)$，其中 $S$ 为状态数，$m$ 为递推步数。

构建状态向量 $V_t$：
将第 $t$ 步的所有 DP 状态按顺序排成一个 $1 \times S$ 的行向量(或 $S \times 1$ 的列向量)

构造转移矩阵 $M$：
转移矩阵 $M$ 的维度为 $S \times S$。
其中 $M_{i, j}$ 的含义是：从第 $t$ 步的状态 $i$，一步转移到第 $t+1$ 步的状态 $j$ 的方案数。

矩阵相乘进行转移：
我们可以观察矩阵相乘的过程
$$c_{i,j}=\sum_k a_{i,k}\cdot b_{k,j}$$
表示经过一次转移从 $i \to j$ 的方案数。
