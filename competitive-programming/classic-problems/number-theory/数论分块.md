# 1 问题

给定 $n$，$k$ 求
$$\sum^n_{i=1}i\cdot\left\lfloor\frac{k}{i}\right\rfloor$$

---
# 2 解答

对于给定的被除数 $k$，满足 $t=\left\lfloor\frac{k}{i}\right\rfloor$ 相等的 $i$ 的取值范围是一个区间 $[l, r]$。
如果我们已知当前的左端点为 $l$，那么这个区间的右端点 $r$ 可以通过公式直接计算
$$r = \min\left\{\left\lfloor \frac{k}{t} \right\rfloor,n\right\}$$
整个块的贡献就为
$$\frac{(r - l + 1)(l + r)}{2}\cdot t$$

```cpp
void solve() {
    ll n, k;
    while (cin >> n >> k) {
        n = min(n, k);
        ll res = 0;
        for (ll l = 1; l <= n;) {
            ll t = k / l;
            ll r = min(k / t, n);
            res += (r - l + 1) * (l + r) / 2 * t;
            l = r + 1;
        }
        cout << res << '\n';
    }
}
```
