# 1 Statement

有一位观众想要在有限的时间内，通过电视观看尽量多的完整节目。
- 已知当天一共有 $n$ 个感兴趣的电视节目。
- 每个节目都有固定的开始时间 $T_s$ 和结束时间 $T_e$。
- 观众同一时间只能看一个节目，并且必须完整看完。
- 如果一个节目的结束时间正好等于另一个节目的开始时间，这两个节目被视为不冲突，可以连续收看。

---
# 2 Solution

贪心策略：优先选择结束时间最早的节目。 
原因：一个节目结束得越早，留给后面节目的时间就越多。

交换论证：
- 假设最优解和贪心解在某一步第一次出现分歧；
- 贪心选的区间结束时间必然**小于等于**最优解在这一步选的区间结束时间；
- 把最优解中那个区间换成贪心选的区间，不会让后面能选的区间**变少**，且不产生新的冲突；
- 于是可以把最优解逐步变成贪心解，同时不减少选中区间的数量，说明贪心解至少和最优解一样好。
