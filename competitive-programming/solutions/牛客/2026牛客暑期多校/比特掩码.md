# 1 Statement

- 定义 $f(x)$ 为 $x$ 的二进制表示中极长连续全 1 段的个数。
- 给定 $n$ 个整数 $a_1,a_2,\dots,a_n$，处理 $m$ 个操作。
- 每次操作有三种类型，分别把 $a_i$ 替换为 `a_i & x`，`a_i | x` 和 `a_i ^ x`。
- 每次操作后输出 $\sum_{i=1}^{n}f(a_i)$
- $1 \leq n,m\leq 3\cdot10^5, 0 \leq a_i, x  < 2^{30}$

---
# 2 Solution

- 对于每一段极长连续全 1 段，其都含一个以 10 结尾的序列，因此
$$f(x)=\sum_{i=0}^{29}\operatorname{bit}_i(x)=1\wedge\operatorname{bit}_{i+1}(x)=0$$
- 我们可以用数组 `cnt[i][j][k]` 维护每位上第 $i$ 位为 $j$ 和第 $i+1$ 位为 $k$ 的状态的总数。
- 对于每次操作，我们可以对每个状态进行转移，即可得到答案。

```cpp
int calc(int type, int bit, int bit_x) {
    if (type == 1) {
        return bit & bit_x;
    }
    else if (type == 2) {
        return bit | bit_x;
    }
    return bit ^ bit_x;
}

int dp[30][2][2];
int tmp[2][2];

void solve() {
    int n;
    cin >> n;
    mem(dp, 0);
    for (int i = 0; i < n; i++) {
        int val;
        cin >> val;
        for (int j = 0; j < 30; j++) {
            dp[j][val >> j & 1][val >> (j + 1) & 1]++;
        }
    }
    int m;
    cin >> m;
    for (int i = 0; i < m; i++) {
        int type, x;
        cin >> type >> x;
        for (int j = 0; j < 30; j++) {
            mem(tmp, 0);
            int a = x >> j & 1;
            int b = x >> (j + 1) & 1;
            for (int l = 0; l <= 1; l++) {
                for (int r = 0; r <= 1; r++) {
                    tmp[calc(type, l, a)][calc(type, r, b)] += dp[j][l][r];
                }
            }
            for (int l = 0; l <= 1; l++) {
                for (int r = 0; r <= 1; r++) {
                    dp[j][l][r] = tmp[l][r];
                }
            }
        }
        ll ans = 0;
        for (int j = 0; j < 30; j++) ans += dp[j][1][0];
        cout << ans << '\n';
    }
}
```
