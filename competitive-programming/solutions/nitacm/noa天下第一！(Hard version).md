# 1 Statement

给一棵 $n$ 个节点的树，和一个常数 $k$。  
对于每个节点 $x$，定义受影响节点为：与 $x$ 距离不超过 $k$ 的节点。  
一个受影响节点 $y$ 的拥挤程度定义为：所有受影响节点到 xx 的路径中经过 yy 的次数。

对于每个 $x$，输出：
1. 受影响节点的数量；
2. 所有受影响节点拥挤程度的乘积，对 109+7 取模。
