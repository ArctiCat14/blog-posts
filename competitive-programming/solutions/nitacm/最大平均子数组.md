# 1 问题

给定一个长度为 $n$ 的整数数组，求出平均值最大的**子数组**，要求子数组长度至少为 $2$。

---
# 2 解答

任何长度大于 $3$ 的连续段，都可以拆解成若干个由长度为 $2$ 和 $3$ 组成的小段。

而连续段的平均值不可能大于每个小段单独的平均值，即
$$\min_{1\le i\le n}\mathrm{Avg}_i \le \mathrm{Avg}_\mathrm{Total} \le \max_{1\le i\le n}\mathrm{Avg}_i$$ 因此我们只需要看长度为 $2$ 和 $3$ 的所有子数组的平均值就能求出答案了。
