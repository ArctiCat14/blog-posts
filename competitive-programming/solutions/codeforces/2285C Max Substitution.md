# 1 Statement

给你一个长度为 $n$ 的序列 $a$。只要此时 $a$ 中含有唯一一个最大值，你就可以进行这个操作，将这个最大值替换成小于他的任意正整数 $x,\ 1\leq x < \max(a)$。

求对这个序列 $a$ 进行任意次(可以为零次)操作后可以得到的不同序列的个数。

---
# 2 Solution

考虑将 $a$ 进行降序排序，这样不会影响答案。可以发现被修改的数会构成这个序列的一个前缀。

考虑第 $i$ 个位置。如果他可以被修改，则第 $i$ 个位置之前的数 $a_j\ (1\leq j < i)$ 都落在区间 $[1, a_i - 1]$ 之内，且在第 $i$ 个位置上的数需要被修改，范围同为 $[1, a_i - 1]$。

因此，可得**操作至**第 $i$ 个位置对不同序列的个数的贡献为 $(a_i - 1)^i$。
