# 1 Statement

给定 $n\ (1\leq n\leq 5000)$ 个元素排成一行，编号为 $1, 2, \dots, n$。每个元素 $i$ 附带两组区间 $[l_i, r_i]$ 和 $[u_i, v_i]$。

我们需要选择一个长度为 $m$ 的子序列。
若原第 $i$ 个元素在子序列中排在第 $j$ 位($1 \le j \le m$)，则它必须满足：
1. $j \notin [l_i, r_i]$
2. $m - j + 1 \notin [u_i, v_i]$
当且仅当子序列中的每一个元素都满足上述限制时，该子序列才是合法子序列。求合法子序列的最大可能长度 $m$。

---
# 2 Solution

对于一个长度为 $m$ 的最终子序列，元素 $i$ 若处于子序列的第 $j$ 位，其右排名为 $m - j + 1$。
因此，某个元素能否占据第 $j$ 位完全取决于固定的 $m$。

基于此，我们可以枚举子序列的最终长度 $m$。
对于固定的 $m$，从左到右扫描原始序列，依次填充子序列的位置 $1,2,\dots,m$。
只要当前元素满足条件，就立即选择它。

为了证明这种贪心选择，假设可行解为位置 $j$ 选择了元素 $x$，而贪心算法选择了较早的有效元素 $y$。
用 $y$ 替换 $x$ 后，原方案中后面的每个元素都是可用的，并且不会减少必须进行后续选择的剩余后缀。
因此，只要存在可行解，贪心算法也会成功。
