# C Counting Arrays

## 1 Statement

给你两个整数 $n,m\ (1\leq n \leq 100, 0\leq m\leq n)$，求出序列 $a_1, a_2,\dots,a_n$ 的种类数，该序列需要满足一般条件：
$$a_1 = 0, 0\leq a_i - a_{i - 1} \leq 1\ (2 \leq i \leq n)$$
同时，还要满足 $m$ 个限制。定义序列的前缀和为 $s_i=\sum_{1\leq j \leq i}a_j$。
则第 $i$ 个限制为两个整数 $p_i, v_i$，使得 $s_{p_i}=v_i$。
限制按 $p_i$ 升序给出。

## 2 Solution

注意到两个相邻限制 $i, i+1\ (1\leq i < m)$ 之间的关系是根据他们各自位置上的那个数 $a_{p_i}, a_{p_{i+1}}$ 决定的。
并且，前一个数对后一个数的约束为
$$a_{p_i}\leq a_{p_{i+1}} \leq a_{p_i} + (p_{i+1}-p_i)$$
这启发我们定义 $\mathrm{dp2}[x]$，表示当前位置 $p$ 上的数为 $x$ 时，序列 $a_1, a_2,\dots, a_p$ 的合法种类数。
因此，我们只需要考虑两个相邻限制之间要如何转移即可。

注意到每次的转移过程都是相同的，即构造满足一般条件的新序列，而这样的过程是可以预处理的。
定义 $\mathrm{dp}[i][j][k]$，表示长度为 $i+1$、末位置上的数为 $j$、序列总和为 $k$，且满足一般条件的序列的种类数。
有转移方程：
$$\begin{cases}
\mathrm{dp}[i][j][k + j]=\mathrm{dp}[i][j][k + j] + \mathrm{dp}[i - 1][j][k] \\
\mathrm{dp}[i][j + 1][k + j + 1]=\mathrm{dp}[i][j + 1][k + j + 1] + \mathrm{dp}[i - 1][j][k]
\end{cases}$$
代码：
```cpp
const int MAXN = 100;
const int MAXV = 4950;
const int MOD = 998244353;
vector<vector<vector<int>>> dp(MAXN, vector<vector<int>>(MAXN, vector<int>(MAXV + 1)));

void init() {
    dp[0][0][0] = 1;
    for (int i = 1; i < MAXN; i++) {
        for (int j = 0; j < i; j++) {
            int l = j * (j + 1) / 2;
            int r = j * (2 * i - j - 1) / 2;
            for (int k = l; k <= r; k++) {
                int cur = dp[i - 1][j][k];
                if (!cur) continue;
                dp[i][j][k + j] += cur;
                dp[i][j][k + j] %= MOD;
                dp[i][j + 1][k + j + 1] += cur;
                dp[i][j + 1][k + j + 1] %= MOD;
            }
        }
    }
}
```

我们把每次从位置 $p_i$ 到 $p_{i+1}$ 的转移都考虑为一个新的序列的产生，枚举这两个位置上的数 $j, k$，我们可以确定这个序列的总和为
$$w=v_{i+1}-v_{i}- (p_{i+1} - p_i)\cdot j$$
有 $\mathrm{dp2}[x]$ 的转移方程：
$$\mathrm{ndp2}[k]=\mathrm{ndp2}[k]+\mathrm{dp2}[j]\cdot \mathrm{dp}[p_{i+1}-p_i][k-j][w]$$

最后还要考虑最后一个限制位置 $p_m$ 到 $n$ 的种类数，显然为 $2^{n-p_m}$。

代码：
```cpp
void solve(int cas) {
    int n, m;
    cin >> n >> m;
    vector<int> dp2(100);
    dp2[0] = 1;
    ll prev_p = 1, prev_v = 0;
    for (int i = 0; i < m; i++) {
        ll p, v;
        cin >> p >> v;
        vector<int> ndp2(100);
        for (int j = 0; j < prev_p; j++) {
            if (dp2[j] == 0) continue;
            ll w = v - prev_v - (p - prev_p) * j;
            if (w < 0 || w > MAXV) continue;
            for (int k = j; k < p; k++) {
                if (dp[p - prev_p][k - j][w] == 0) continue;
                ndp2[k] += 1LL * dp2[j] * dp[p - prev_p][k - j][w] % MOD;
                ndp2[k] %= MOD;
            }
        }
        prev_p = p;
        prev_v = v;
        swap(ndp2, dp2);
    }
    ll ans = 0;
    for (int i = 0; i < 100; i++) {
        ans += dp2[i];
        ans %= MOD;
    }
    ans *= qpow(2, n - prev_p);
    ans %= MOD;
    cout << ans << '\n';
}
```
