# 1 Statement

有一个 $n\times n$ 的矩阵，里面全是非负数。
从中取出若干个数，要求取出的数中任意两个数之间不相邻。
求取出的数的总和的最大值。

---
# 2 Solution

这是一道 SOS DP(Sum Over Subsets Dynamic Programming)。

先把所有合法的状态的二进制表示预处理出来，合法的状态即
$$S=\{s\mid s\& (s\ll 1) = 0, 0\le  s < 2^n\}$$

定义 $\mathrm{sum}[s]$ 为在当前行下，状态为 $s$ 时的总和。
定义 $\mathrm{dp}[s]$ 为在当前行下，状态为 $s$ 时的最大值。
使用滚动数组优化，设 $\mathrm{dp}$ 为上一行的值，$\mathrm{ndp}$ 为当前行的值，有状态转移方程：
$$\mathrm{ndp}[s]=\mathrm{sum}[s]+\max_{p\subseteq \overline{s}}\mathrm{dp}[p]$$
其中， $\overline{s}$ 为 $s$ 状态的补集。$\max_{p\subseteq \overline{s}}\mathrm{dp}[p]$ 可以通过 SOS DP 求出。

```cpp
void solve() {
    int n;
    while (cin >> n) {
        int full = (1 << n) - 1;
        vector<int> states;
        for (int s = 0; s <= full; s++) {
            if ((s & (s << 1)) == 0) {
                states.emplace_back(s);
            }
        }
        vector<ll> dp(1 << n);
        for (int r = 1; r <= n; r++) {
            vector<ll> col(n + 1);
            for (int i = 1; i <= n; i++) cin >> col[i];
            vector<ll> sum(1 << n);
            for (auto s : states) {
                for (int i = 0; i < n; i++) {
                    if (s & 1 << i) sum[s] += col[i + 1];
                }
            }
            if (r == 1) {
                for (auto s : states) {
                    dp[s] = sum[s];
                }
            }
            else {
                vector<ll> f(dp);
                for (int i = 0; i < n; i++) {
                    for (int s = 0; s <= full; s++) {
                        if (s & (1 << i)) {
                            f[s] = max(f[s], f[s ^ (1 << i)]);
                        }
                    }
                }
                vector<ll> ndp(1 << n);
                for (auto s : states) {
                    ndp[s] = sum[s] + f[full ^ s];
                }
                swap(ndp, dp);
            }
        }
        cout << *max_element(all(dp)) << '\n';
    }
}
```
