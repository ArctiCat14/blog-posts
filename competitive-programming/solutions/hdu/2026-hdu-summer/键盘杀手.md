# 1 Statement

- 给出一个长度为 $n$ 的序列 $a_1, a_2, \dots, a_n$，特别地 $a_0=a_{n+1}=0$
- 你可以进行若干次操作，每次操作形如：选择一个整数 $i (1\leq i \leq n)$，花费 $\max\{a_{i-1},a_{i+1}\}$ 的代价将 $a_i$ 赋值为 $0$。
- 求出将 $a_1,a_2,\dots,a_n$ 均赋值为 $0$ 的最小代价总和。
- $1\leq n \leq 10^5,1\leq a_i \leq 10^9$

---
# 2 Solution

- 对于删除 $a_i$ 的代价，只需要考虑 $a_{i-1}, a_{i+1}$ 相对 $a_i$ 删除的顺序。
- 考虑动态规划，设 $f_{i,j}$ 为删除前 $i$ 个元素的总代价最小值，$j=0$ 表示 $a_i$ 相对 $a_{i+1}$ 更早删除，$j=1$ 表示 $a_i$ 相对 $a_{i+1}$ 更晚删除，有状态转移方程
$$\begin{cases}
f_{i,0}=\min\{f_{i-1,0}+a_{i+1},f_{i-1,1}+\max\{a_{i-1},a_{i+1}\}\}   \\ 
f_{i,1}=\min\{f_{i-1,0},f_{i-1,1}+a_{i-1}\}
\end{cases}$$

```cpp
void solve(int cas) {
    int n;
    cin >> n;
    vector<ll> a(n + 2);
    for (int i = 1; i <= n; i++) cin >> a[i];
    ll dp0 = a[2];
    ll dp1 = 0;
    for (int i = 2; i <= n; i++) {
        ll ndp0 = min(dp0 + a[i + 1], dp1 + max(a[i - 1], a[i + 1]));
        ll ndp1 = min(dp0, dp1 + a[i - 1]);
        dp0 = ndp0;
        dp1 = ndp1;
    }
    cout << min(dp0, dp1) << '\n';
}
```
